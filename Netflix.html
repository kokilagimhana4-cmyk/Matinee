Matinee

Movies and TV, always up to date

Trending titles, new releases and what is coming soon. This page updates itself, so nobody has to add films by hand.
Matinee is a free, open-source project (MIT license). It lists titles and trailers only and does not host or stream films. This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability data is provided by JustWatch through TMDB.
